# แผนสำรอง START → FINISH

วางรถตรงกลางช่อง START หันหน้าไปด้านบนของแผนที่หน้า 1 พอจอขึ้น **A** กด **A** ครั้งเดียว รถจะขับตามเวลาและเบรกเมื่อจบเส้นทาง กด **B** เพื่อเบรกกลางทาง หากจะลองอีกครั้ง ให้นำรถกลับไปวางที่ START ในท่าเดิม

### ลงบอร์ดหรือแก้เวลา

- **ลงบอร์ดทันที** ดาวน์โหลด [finish-only.hex](./finish-only.hex) ด้วยปุ่ม **Download raw file** แล้วคัดลอกลงไดรฟ์ **MICROBIT** รอไฟหลังบอร์ดหยุดกะพริบ
- **แก้โค้ด** เปิดโปรเจกต์ใหม่ใน [MakeCode สำหรับ micro:bit](https://makecode.microbit.org/) เพิ่มส่วนขยาย **MOTION:BIT** ของ Cytron เลือกภาษา **Python** แล้ววาง [main.py ในโฟลเดอร์นี้](./main.py) ทั้งไฟล์ เมื่อแก้ค่าแล้วกด **Download** เพื่อสร้าง HEX ใหม่

### ทางวิ่งตามภาพหน้า 1

นับคอลัมน์จากซ้าย และนับแถวจากบน ภาพตัวอย่างมี 8 คอลัมน์ × 4 แถว ช่องละ 30 ซม.

| ช่วง | เดินจากกึ่งกลางช่องถึงกึ่งกลางช่อง |
|---|---|
| ออกจาก START | จาก (1,4) ขึ้น 3 ช่องถึง (1,1) |
| อ้อมขอบดำด้านซ้าย | เลี้ยวขวา เดิน 2 ช่องถึง (3,1) แล้วเลี้ยวขวา เดิน 1 ช่องถึง (3,2) |
| เข้าช่องกลาง | เลี้ยวขวา เดิน 1 ช่องถึง (2,2) แล้วเลี้ยวซ้าย เดิน 1 ช่องถึง (2,3) |
| ข้ามสะพาน | เลี้ยวซ้าย เดินตรง 5 ช่องถึง (7,3) |
| เข้า FINISH | เลี้ยวขวา เดิน 1 ช่องถึง (7,4) แล้วเบรก |

### จูนกับรถจริง

1. ตั้ง `ROUTE = [1]` เพื่อทดสอบเดินตรงบนพื้นราบ ใน `main.py` กำลังเดินหน้าฝั่งซ้าย M1/M2 คือ `LEFT_FORWARD_SPEED = 255` และฝั่งขวา M3/M4 คือ `RIGHT_FORWARD_SPEED = 240` ถ้ายังเบนซ้ายให้ลดค่าขวาทีละ 5 ถ้าเริ่มเบนขวาให้เพิ่มค่าขวาทีละ 5 (สูงสุด 255)
2. เมื่อรถตรงแล้ว วัดระยะจากหยุดนิ่งถึงหยุดนิ่ง แล้วปรับ `TILE_MS` (เริ่มที่ 500 ms) ให้ได้ 30 ซม. ตอนหมุนทั้งสองฝั่งใช้ `TURN_SPEED = 255` ลอง `ROUTE = [TURN_RIGHT]` และ `ROUTE = [TURN_LEFT]` แล้วจูน `RIGHT_90_MS` และ `LEFT_90_MS` (เริ่มที่ 300 ms) ให้ได้ 90° ทั้งสองทิศ
3. คืนค่า `ROUTE` ตามเส้นทางในไฟล์ แล้วลองทั้งรอบรวมช่วงสะพาน เวลานับจากคำสั่งมอเตอร์ รถจึงหยุดตามเวลาที่ตั้งแม้ล้อไถลหรือรถเบนออกจากช่อง ถ้าผังจริงเปลี่ยนให้แก้ลำดับและจำนวนช่องใน `ROUTE`

ตามกติกาข้อ 12.3 คะแนน FINISH 20 คะแนนต้องส่งวัตถุครบ 6 ชิ้นและผ่าน CheckPoint ครบ 2 จุดก่อน การวิ่งแผนนี้อย่างเดียวจึงไม่ได้คะแนน FINISH [กติกาและภาพตัวอย่างสนาม](https://drive.google.com/file/d/1AW1nNlbbKiRLe7aYKGDlfmVJBVDNf9X0/view)
