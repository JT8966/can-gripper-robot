# แผนสำรอง START → CheckPoint 2 จุด → FINISH

วางรถกลาง START หันขวาตามภาพสนามจริงที่มี START อยู่ด้านล่าง พอจอขึ้น **A** กด **A** ครั้งเดียว รถจะขับตามเวลาผ่านจุดเหลืองล่าง แล้วจุดเหลืองบน และเข้า FINISH กด **B** เพื่อเบรกกลางทาง หากจะลองอีกครั้ง ให้นำรถกลับไปวางที่ START ในท่าเดิม

โค้ดนี้ขับเฉพาะล้อ ไม่สั่งเซอร์โว ไม่ใช้เข็มทิศ NB142 หรือเซ็นเซอร์สี จึงไม่ยืนยันว่าทับจุดเหลืองจริงและไม่หยุดหลบสิ่งกีดขวาง ต้องจัดก้ามให้ไม่เกี่ยวสนามและจูนระยะ/มุมกับรถจริงก่อนใช้

### ลงบอร์ดหรือแก้เวลา

- **ลงบอร์ดทันที** ดาวน์โหลด [finish-only.hex](./finish-only.hex) ด้วยปุ่ม **Download raw file** แล้วคัดลอกลงไดรฟ์ **MICROBIT** รอไฟหลังบอร์ดหยุดกะพริบ
- **แก้โค้ด** เปิดโปรเจกต์ใหม่ใน [MakeCode สำหรับ micro:bit](https://makecode.microbit.org/) เพิ่มส่วนขยาย **MOTION:BIT** ของ Cytron เลือกภาษา **Python** แล้ววาง [main.py ในโฟลเดอร์นี้](./main.py) ทั้งไฟล์ เมื่อแก้ค่าแล้วกด **Download** เพื่อสร้าง HEX ใหม่

### ทางวิ่งตามภาพสนามจริง

นับคอลัมน์จากซ้ายและแถวจากบน สนามมี 8 คอลัมน์ × 4 แถว ช่องละ 30 ซม.

| ช่วง | เดินจากกึ่งกลางช่องถึงกึ่งกลางช่อง |
|---|---|
| ออกจาก START | จาก (3,4) หันขวา ข้ามลูกระนาดถึง (6,4) แล้วเลี้ยวขึ้น (6,3) |
| จุดเหลืองล่าง | ไปขวาถึง (7,3) แล้วลงถึง CheckPoint (7,4) ไม่ตัดข้ามเส้นดำจาก (6,4) |
| ออกจากจุดล่าง | หมุนขวา 90° สองครั้ง ขึ้นกลับ (7,3) แล้วไปซ้ายถึง (6,3) |
| จุดเหลืองบน | ขึ้น (6,2) ไปขวา (7,2) แล้วขึ้นถึง CheckPoint (7,1) |
| ออกจากจุดบน | หมุนขวา 90° สองครั้ง ลงกลับ (7,2) แล้วไปซ้ายถึง (6,2) ไม่ข้ามเส้นดำระหว่าง (7,1) กับ (6,1) |
| เหนือ FINISH | ขึ้น (6,1) แล้วไปซ้ายถึง (5,1) |
| เข้า FINISH | ลงถึง (5,2) แล้วเบรก |

พิกัดเป็นแผนจากภาพ ไม่ใช่ตำแหน่งที่เซ็นเซอร์วัดได้ การทดสอบจำลองตรวจเส้นทางกึ่งกลางรถเท่านั้น ยังไม่ยืนยันระยะเผื่อล้อ/ก้ามขณะเลี้ยวในช่องแคบ โดยเฉพาะการกลับตัวที่จุดเหลืองทั้งสองจุด

### จูนกับรถจริง

1. ตั้ง `ROUTE = [1]` เพื่อทดสอบเดินตรงบนพื้นราบ ใน `main.py` กำลังเดินหน้าฝั่งซ้าย M1/M2 คือ `LEFT_FORWARD_SPEED = 255` และฝั่งขวา M3/M4 คือ `RIGHT_FORWARD_SPEED = 240` ถ้ายังเบนซ้ายให้ลดค่าขวาทีละ 5 ถ้าเริ่มเบนขวาให้เพิ่มค่าขวาทีละ 5 (สูงสุด 255)
2. เมื่อรถตรงแล้ว วัดระยะจากหยุดนิ่งถึงหยุดนิ่ง แล้วปรับ `TILE_MS` (เริ่มที่ 500 ms) ให้ได้ 30 ซม. ตอนหมุนทั้งสองฝั่งใช้ `TURN_SPEED = 255` ลอง `ROUTE = [TURN_RIGHT]` และ `ROUTE = [TURN_LEFT]` แล้วจูน `RIGHT_90_MS` และ `LEFT_90_MS` (เริ่มที่ 300 ms) ให้ได้ 90° ทั้งสองทิศ
3. คืนค่า `ROUTE` ตามเส้นทางในไฟล์ แล้วลองทั้งรอบรวมช่วงลูกระนาด เวลานับจากคำสั่งมอเตอร์ รถจึงหยุดตามเวลาที่ตั้งแม้ล้อไถลหรือรถเบนออกจากช่อง ถ้าผังจริงเปลี่ยนให้แก้ลำดับและจำนวนช่องใน `ROUTE`

ตามกติกาข้อ 12.3 คะแนน FINISH 20 คะแนนต้องส่งวัตถุครบ 6 ชิ้นและผ่าน CheckPoint ครบ 2 จุดก่อน การวิ่งแผนนี้อย่างเดียวจึงไม่ได้คะแนน FINISH [กติกาและภาพตัวอย่างสนาม](https://drive.google.com/file/d/1AW1nNlbbKiRLe7aYKGDlfmVJBVDNf9X0/view)
