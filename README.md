# หุ่นยนต์คีบกระป๋อง · MOTION:BIT Pro

กด **A** เพื่อค้นหากระป๋อง หุ่นเดินตรงตามเข็มทิศ เมื่อ NB142 เจอกรอบดำ จะเบรก ถอยประมาณ 3 ซม. หมุนขวา 90° แล้วเดินหน้าต่อ วนซ้ำจน HC-SR04 พบวัตถุในระยะคีบ กด **B** เพื่อเบรกล้อและยกเลิกรอบ

## ใช้ไฟล์ไหน

| สิ่งที่ต้องการทำ | ไฟล์ที่ใช้ |
|---|---|
| แก้โค้ดหุ่น เช่น ระยะคีบ เวลาถอย หรือมุมเซอร์โว | `main.ts` ในแท็บ JavaScript ของ MakeCode |
| เปิดโปรเจกต์พร้อมส่วนขยาย MOTION:BIT | นำเข้าลิงก์รีโปทั้งโปรเจกต์ MakeCode จะอ่าน `pxt.json` เพื่อโหลดส่วนขยาย |
| ลงโปรแกรมบน micro:bit | ใช้ไฟล์ `.hex` ที่ MakeCode สร้างเมื่อกด **Download** |

## ลงโปรแกรมครั้งแรก

1. เปิด [MakeCode สำหรับ micro:bit](https://makecode.microbit.org/) แล้วเลือก **Import → Import URL**
2. วางลิงก์ `https://github.com/JT8966/can-gripper-robot` แล้วกดนำเข้า
3. เสียบสาย USB ที่ส่งข้อมูลได้จากคอมพิวเตอร์ **เข้าพอร์ต USB บนตัว micro:bit** แล้วกด **Download** ใน MakeCode
4. ถ้าเบราว์เซอร์บันทึกไฟล์ `.hex` ลงคอม ให้คัดลอกไฟล์นั้นไปที่ไดรฟ์ **MICROBIT** แล้วรอไฟด้านหลังบอร์ดหยุดกะพริบ ถ้าจับคู่บอร์ดผ่าน WebUSB แล้ว ปุ่ม Download จะส่งโปรแกรมลงบอร์ดโดยตรง [คู่มือโอนโปรแกรมของ MakeCode](https://makecode.microbit.org/device/usb)

## พอร์ตของหุ่น

| อุปกรณ์ | พอร์ต MOTION:BIT Pro |
|---|---|
| ล้อซ้าย 2 ตัว | ต่อทีละตัวที่คู่ M1A/M1B และคู่ M2A/M2B ทิศเดินหน้าคือ M1A และ M2A |
| ล้อขวา 2 ตัว | ต่อทีละตัวที่คู่ M3A/M3B และคู่ M4A/M4B ทิศเดินหน้าคือ M3A และ M4A |
| เซอร์โว 1 ยก–ลด rack | S1 |
| เซอร์โว 2 และ 3 หนีบซ้ายและขวา | S2 ซ้าย, S3 ขวา |
| เซอร์โว 4 และ 5 หมุนชุดคีบ | S4 ซ้าย, S5 ขวา |
| HC-SR04 รุ่น 5V แบบ 4 ขา | VCC → ขา 5V, GND → GND, TRIG → P1, ECHO → P2 ผ่านตัวแบ่งแรงดัน |
| TCS3472 | I²C ใช้ SDA (P20), SCL (P19), GND และ 3V3 สำหรับโมดูลที่รองรับ |
| NB142 รุ่นเอาต์พุตดิจิทัล 5 ช่องที่รองรับ 3.3V | VCC → 3V3, GND → GND และเอาต์พุตซ้ายสุดถึงขวาสุด → P12, P13, P14, P15, P16 ที่ขา Signal ของ GPIO |

**ลดแรงดัน ECHO ก่อนต่อ P2** ต่อ ECHO → ตัวต้านทาน 10 kΩ → จุดร่วมที่ต่อเข้า P2 แล้วต่อจากจุดร่วมนั้นผ่านตัวต้านทาน 10 kΩ อีกตัวลง GND แรงดัน 5V จะลดเหลือประมาณ 2.5V [ผัง HC-SR04 สำหรับบอร์ด 3.3V](https://learn.adafruit.com/ultrasonic-sonar-distance-sensors/pinouts)

### ตั้งระยะและลำดับคีบ

- `PICKUP_DISTANCE_CM` คือค่า X วัดจากหน้าหัว HC-SR04 ตั้งไว้ **10 ซม. ชั่วคราว** วางกระป๋องที่ตำแหน่งหนีบจริงแล้วปรับค่านี้ หุ่นเบรกทันทีที่อ่านค่าใกล้ครั้งแรก และคีบเมื่อวัดซ้ำแล้วยังอยู่ในระยะ สัญญาณที่หมดเวลาจะไม่นับเป็นวัตถุ เซนเซอร์วัดได้ทั้งกระป๋องและวัตถุอื่นด้านหน้า
- `REVERSE_3CM_MS` คือเวลาถอยที่ความเร็ว `SPEED` ตั้งต้น 180 มิลลิวินาที ขีดจุดอ้างอิงที่ล้อแล้วลองวัดระยะบนพื้นจริง เช่น ถอยได้ 4.5 ซม. ให้ลองลดเป็น `180 × 3 / 4.5 = 120` มิลลิวินาที ปรับใหม่เมื่อเปลี่ยนพื้น โหลด หรือความเร็ว
- ตอนเริ่ม S1 ยกชุดคีบ, S4/S5 ตั้งท่าเตรียม และ S2/S3 เปิดปากคีบ เมื่อถึงระยะ รถหยุด → S1 ลด → S2/S3 หนีบ → S4/S5 รับคำสั่งไปมุมหลังหนีบ แล้วจบรอบโดยหนีบค้าง มุม `ROTATE_LEFT_AFTER_GRIP` และ `ROTATE_RIGHT_AFTER_GRIP` ตั้งเท่าท่าเตรียมที่ 90° จนกว่าจะกำหนดมุมหมุนจริง
- หากต่อ TCS3472 ไว้ โค้ดจะรายงาน `RED` หรือ `BLUE` เมื่อเข้าสู่แถบสีนั้นผ่าน Serial บน USB ส่วนการเริ่มคีบใช้ระยะจาก HC-SR04

### ทดลองกับหุ่นจริง

1. ปิดไฟก่อนย้ายสายเซอร์โวให้ตรงกับผัง S1–S5 ถ้าทุกตัวรองรับ 5V ให้ตั้ง VCC1 และ VCC2 ที่ 5V ตรวจพิกัดกระแสรวมของเซอร์โวขณะรับโหลด เพราะภาคจ่าย 5V ของบอร์ดรองรับสูงสุด 3A รวม [คู่มือ MOTION:BIT Pro](https://cdn.robotshop.com/media/C/Cyt/RB-Cyt-437/pdf/cytron-motionbit-pro-12v-robotics-expansion-board-for-microbit-datasheet.pdf)
2. โค้ดใช้ rack แบบเซอร์โวกำหนดมุมและติดตั้งเซอร์โวคู่แบบกระจกเงา ลองทิศทางก่อนยึดก้าน ปรับมุมยก–ลด อ้า–หนีบ และหมุน ให้สองฝั่งช่วยกันออกแรงและหยุดก่อนสุดกลไก
3. ตั้ง NB142 ใต้หน้ารถ หันหัวอ่านลงพื้น ทดลองเทปดำทีละช่อง ค่า `BLACK_LEVEL = 1` ใช้เมื่อวัดบนดำได้ใกล้ 3.3V และพื้นสว่างใกล้ 0V หากกลับกันให้ตั้งเป็น `0`
4. ปรับเทียบเข็มทิศตามคำแนะนำบนจอ ตรวจว่าการหมุนขวา 90° เพิ่มค่าทิศใกล้ 90° ในท่าติดตั้งจริง ลองขณะมอเตอร์ทำงานด้วย หุ่นจะกลับมาเดินหน้าเมื่อทิศอยู่ในช่วง ±4° สามครั้งติดต่อกัน หากยังเห็นดำหลังถอย เข็มทิศอ่านไม่ได้ หรือหมุนไม่สำเร็จใน 5 วินาที รถจะหยุดและแสดง ✗ หากต้องการยกเลิกระหว่างรอบให้กด B [คู่มือเข็มทิศ MakeCode](https://makecode.microbit.org/reference/input/compass-heading)
