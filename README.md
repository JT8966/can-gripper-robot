# หุ่นยนต์คีบกระป๋อง · MOTION:BIT Pro

หุ่นใช้ micro:bit ควบคุมล้อ 4 ตัวและเซอร์โวแบบกำหนดมุม 5 ตัว เซนเซอร์ TCS3472 หันลงอ่านแถบสีบนพื้น หุ่นรับกระป๋องที่แถบแดงแล้วนำไปวางที่แถบน้ำเงิน

## ใช้ไฟล์ไหน

| สิ่งที่ต้องการทำ | ไฟล์ที่ใช้ |
|---|---|
| แก้โค้ดหุ่น เช่น ความเร็ว มุมแขน หรือองศาเลี้ยว | `main.ts` ในแท็บ JavaScript ของ MakeCode |
| เปิดโปรเจกต์พร้อมส่วนขยาย MOTION:BIT | นำเข้าลิงก์รีโปทั้งโปรเจกต์ MakeCode จะอ่าน `pxt.json` เพื่อโหลดส่วนขยาย |
| ลงโปรแกรมบน micro:bit | ใช้ไฟล์ `.hex` ที่ MakeCode สร้างเมื่อกด **Download** |

## ลงโปรแกรมครั้งแรก

1. เปิด [MakeCode สำหรับ micro:bit](https://makecode.microbit.org/) แล้วเลือก **Import → Import URL**
2. วางลิงก์ `https://github.com/JT8966/can-gripper-robot` แล้วกดนำเข้า
3. เสียบสาย USB ที่ส่งข้อมูลได้จากคอมพิวเตอร์ **เข้าพอร์ต USB บนตัว micro:bit** แล้วกด **Download** ใน MakeCode
4. ถ้าเบราว์เซอร์บันทึกไฟล์ `.hex` ลงคอม ให้คัดลอกไฟล์นั้นไปที่ไดรฟ์ **MICROBIT** แล้วรอไฟด้านหลังบอร์ดหยุดกะพริบ ถ้าจับคู่บอร์ดผ่าน WebUSB แล้ว ปุ่ม Download จะส่งโปรแกรมลงบอร์ดโดยตรง [คู่มือโอนโปรแกรมของ MakeCode](https://makecode.microbit.org/device/usb)

## พอร์ตของหุ่น

| อุปกรณ์ | พอร์ต MOTION:BIT Pro |
|---|---|
| ล้อซ้าย 2 ตัว | M1 และ M2 |
| ล้อขวา 2 ตัว | M3 และ M4 |
| เซอร์โวล่าง หมุนเฟืองยก–ลด rack | S4 |
| ข้อศอกซ้าย หมุนแขนส่วนปลาย | S3 |
| ข้อศอกขวา หมุนแขนส่วนปลาย | S5 |
| ปากคีบซ้าย | S8 |
| ปากคีบขวา | S6 |
| TCS3472 | I²C ใช้ SDA (P20), SCL (P19), GND และ 3V3 สำหรับโมดูลที่รองรับ |
| NB142 รุ่นเอาต์พุตดิจิทัล 5 ช่องที่รองรับ 3.3V | VCC → 3V3, GND → GND และเอาต์พุตซ้ายสุดถึงขวาสุด → P12, P13, P14, P15, P16 ที่ขา Signal ของ GPIO |

### ตั้งเซนเซอร์กรอบสนาม NB142

ติด NB142 ใต้ด้านหน้ารถให้หัวอ่านลงพื้นและอยู่หน้าล้อ วางหุ่นบนพื้นสว่างภายในกรอบดำ ระหว่างเดินและหมุน หากช่องใดช่องหนึ่งอ่านเจอดำ หุ่นจะเบรกล้อและยกเลิกรอบ ย้ายหุ่นกลับเข้ากรอบก่อนกด A ใหม่ เผื่อระยะหยุดและมุมตัวถังที่อาจกวาดเลยหัวอ่านขณะหมุน

ก่อนวิ่ง วัดเอาต์พุตช่องกลางเทียบ GND บนเทปดำและพื้นจริงที่ระยะติดตั้ง ถ้าดำได้ใกล้ 3.3V และพื้นได้ใกล้ 0V ให้ใช้ `BLACK_LEVEL = 1` ถ้ากลับกันให้ตั้งเป็น `0` ขา GPIO รับสัญญาณ 3.3V หากโมดูลเป็นรุ่น 5V เท่านั้น ต้องปรับระดับสัญญาณก่อนต่อ

ให้ TCS3472 ผ่านจุดรับสีแดงและจุดวางสีน้ำเงินภายในกรอบ ทดสอบ NB142 บนแถบสีทั้งสองด้วย หากอ่านเป็นดำให้ติดแถบสีเยื้องแนว NB142 ให้ผ่านเฉพาะ TCS3472 เพราะกรอบดำมีสิทธิ์หยุดรถก่อนคำสั่งคีบและวาง

### ตั้งทิศเดินและมุมเลี้ยว

ใช้เข็มทิศใน micro:bit เมื่อจอขอปรับเทียบ ให้เอียงบอร์ดตามคำแนะนำ แล้ววางรถให้หัวชี้ไปจุดรับก่อนเริ่มวิ่ง ตรวจว่าหมุนรถขวา 90° แล้วค่าทิศเพิ่มใกล้ 90° ในท่าติดตั้งจริง และลองอ่านค่าขณะมอเตอร์ทำงาน เพราะสนามแม่เหล็กอาจรบกวนเข็มทิศ [คู่มือ MakeCode](https://makecode.microbit.org/reference/input/compass-heading)

รถบันทึกทิศก่อนออกตัวและปรับความเร็วล้อเพื่อรักษาทิศ หลังคีบจะหมุนล้อแบบสวนทางและตรวจให้ทิศอยู่ในช่วง ±4° สามครั้งติดกันก่อนวิ่งต่อ หากเข็มทิศอ่านไม่ได้หรือหมุนไม่ถึงมุมใน 5 วินาที รถจะหยุดและยกเลิกรอบ

## ทดลองวิ่ง

ปิดไฟก่อนเสียบหัวเซอร์โว ให้สายสัญญาณตรงขา Signal สายบวกตรง V+ และสายกราวด์ตรง GND ของพอร์ตนั้น ถ้าทั้ง 5 ตัวรองรับ 5V ให้ตั้งจัมเปอร์ VCC1 และ VCC2 ที่ 5V ภาคจ่าย 5V รองรับสูงสุด 3A รวม ตรวจสเปกกระแสของทั้งห้าตัวขณะรับโหลดก่อนใช้ไฟจากบอร์ด [คู่มือ MOTION:BIT Pro](https://cdn.robotshop.com/media/C/Cyt/RB-Cyt-437/pdf/cytron-motionbit-pro-12v-robotics-expansion-board-for-microbit-datasheet.pdf)

โค้ดใช้เซอร์โวแบบกำหนดมุมสำหรับ rack และสมมติว่าเซอร์โวซ้าย–ขวาของแต่ละคู่ติดแบบกระจกเงา ก่อนยึดก้านเข้ากับกลไก ให้ทดสอบทิศและตั้งศูนย์ ปรับค่ามุม `ELBOW_LEFT/RIGHT` และ `GRIP_LEFT/RIGHT` แยกแต่ละฝั่งให้ข้อศอกช่วยกันขยับและปากคีบหุบเข้าหากัน ปรับ `RACK_UP` และ `RACK_DOWN` ให้หยุดก่อนสุดราง หากตัวล่างเป็นเซอร์โวหมุนต่อเนื่อง ให้เปลี่ยนวิธีคุมระยะ rack ก่อนใช้โปรแกรมนี้

ยกล้อให้ลอยและลองกับปากคีบเปล่าก่อน ปรับมุมเซอร์โวที่ต้นไฟล์ `main.ts` ให้เข้ากับแขนจริง แล้วดาวน์โหลดโปรแกรมใหม่ วางแถบแดงให้เซนเซอร์เห็นตอนปากคีบอยู่ตรงกระป๋องพอดี

- **กด A** เพื่อเริ่ม หุ่นขับไปแถบแดง คีบและยกกระป๋อง แล้วขับไปแถบน้ำเงินเพื่อวาง
- **กด B** เพื่อหยุดล้อและยกเลิกงาน ถ้าหาแถบสีไม่พบภายใน 8 วินาทีในแต่ละช่วง หุ่นจะหยุดเอง
- **ตั้งองศาเลี้ยวหลังคีบ** ที่ `TURN_AFTER_PICKUP_DEG` ค่าเริ่มต้น `90` คือเลี้ยวขวา 90° จากแนวเดินเริ่มต้น ตั้ง `-90` เพื่อเลี้ยวซ้าย หรือ `0` เพื่อเดินตรงไปจุดวาง
