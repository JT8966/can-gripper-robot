# หุ่นยนต์คีบกระป๋อง · MOTION:BIT Pro

กด **A** เพื่อรับกระป๋องจากพื้นสีเหลือง แดง เขียว หรือน้ำเงิน แล้วขนไปวางที่แถบสีเดียวกันอีกจุดภายในกรอบ กด **B** เพื่อหยุด

หุ่นมีวงคีบสองชุด แต่ละชุดโอบกระป๋องได้หนึ่งใบ S4 คุมวงขวา และ S5 คุมวงซ้าย ทั้งสองวงหนีบพร้อมกันที่จุดรับ รถจำสีพื้นหนึ่งสีต่อรอบ เมื่อถึงจุดวางสีเดียวกัน S2 หมุนเฉพาะวงขวา แล้วรถปล่อยใบขวาก่อนใบซ้าย

- **ติดครบห้าดวง** เดินตรงตามเข็มทิศ ก่อนคีบใช้ HC-SR04 วัดระยะ หลังคีบใช้ TCS3472 หาจุดวาง
- **ดับหนึ่งถึงสี่ดวง** เบรกแล้วหมุนอยู่กับที่เข้าหาฝั่งที่ยังติด แม้กำลังเลี้ยวขวา 90° ก็เปลี่ยนมาแก้แนวทันที เมื่อครบห้าดวงจึงใช้ทิศใหม่เป็นแนวเดินตรง ถ้าสองฝั่งสมดุล เช่น ดับเฉพาะดวงกลาง ให้ใช้ทิศแก้ล่าสุด (เริ่มด้วยขวา) ถ้ายังติดไม่ครบภายใน 5 วินาทีในช่วงแก้แนวจะหยุดและขึ้น ✗
- **ดับทั้งห้าดวง** ถอยประมาณ 3 ซม. แล้วหมุนขวา 90° หากเริ่มเห็นบางช่องระหว่างหมุน ให้แก้แนวตามช่องที่ติดก่อนเดินต่อ

## ลงโปรแกรมครั้งแรก

### ถ้าจะเปลี่ยนพฤติกรรม ให้แก้ตรงไหน

**ตั้งค่าแขน** เปิด [main.py](./main.py) ในแท็บ Python ของ MakeCode แล้วแก้ตัวเลขหลังเครื่องหมาย `=` ตรงต้นไฟล์ จากนั้นกด **Download** อีกครั้ง ค่า 500 มิลลิวินาทีเท่ากับครึ่งวินาที

| พอร์ต | บรรทัดที่ค้นหาด้วย Ctrl+F | ค่าเริ่มต้น | ค่าที่ใส่ |
|---|---|---|---|
| S1 ราง | `RACK_DOWN_MS` / `RACK_UP_MS` | 500 / 500 ms | เวลาจากท่าขนลงถึงระดับคีบ และเวลาจากระดับคีบกลับขึ้นท่าขน |
| S2 หมุนวงขวา | `ROTATE_RIGHT_MS` / `ROTATE_RETURN_MS` | 500 / 500 ms | เวลาจากท่าขนไปจุดปล่อย และเวลาหมุนคืนถึงตำแหน่งเดิม |
| S4 วงขวา | `GRIP_RIGHT_OPEN` / `GRIP_RIGHT_CLOSED` | 10° / 20° | มุมที่วงอ้าพ้นกระป๋อง และมุมที่วงหุบจับกระป๋องได้พอดี |
| S5 วงซ้าย | `GRIP_LEFT_OPEN` / `GRIP_LEFT_CLOSED` | 20° / 20° | ตอนนี้ทั้งสองคำสั่งอยู่มุมเดียวกัน วัดมุมอ้าจริงของ S5 แล้วใส่ที่ `GRIP_LEFT_OPEN` |

**ถ้ากด B ขณะที่แขนกำลังรับหรือวาง** ล้อจะหยุด และกด A ซ้ำแล้วขึ้น ✗ ให้ประคองกระป๋อง จัดรางและวงขวากลับท่าเริ่ม แล้วกด **RESET** ที่ตัว micro:bit เมื่อจอขึ้น A จึงเริ่มรอบใหม่ได้ ส่วนการกด B ตอนรถกำลังวิ่งขนแล้ว กด A เพื่อขนต่อได้

เปิด `main.py` แล้วกด **Ctrl+F** ค้นหาชื่อในตาราง ค่าที่ปรับกับหุ่นอยู่ต้นไฟล์ มุมปากคีบใช้หน่วยองศา เซอร์โว 360° ใช้ค่าควบคุมทิศและความเร็ว เวลารอใช้มิลลิวินาที ส่วนคำสั่ง `wait_micros` ของอัลตราโซนิกใช้ไมโครวินาที

| อยากเปลี่ยนอะไร | ค้นหาในโค้ด | วิธีปรับ |
|---|---|---|
| ให้รถเข้าใกล้กระป๋องอีกก่อนหยุด | `PICKUP_DISTANCE_CM` | เช่น เปลี่ยน 10 เป็น 8 เพื่อยืนยันการคีบภายใน 8 ซม. จากหน้าหัว HC-SR04 |
| ถอยไกลหรือสั้นลง | `REVERSE_3CM_MS` | เพิ่มเวลาถ้าอยากถอยไกลขึ้น แล้ววัดบนพื้นจริงอีกครั้ง |
| กำลังล้อ | `SPEED` | 255 คือเต็มกำลัง ค่านี้มีผลทั้งเดินหน้า ถอย และหมุน ถ้าแก้ให้วัดระยะถอยและมุมหยุดใหม่ |
| มุมเลี้ยวขวา | `TURN_DEG` | ตั้งเป็น 90 สำหรับมุมฉาก หรือ 60 สำหรับเลี้ยวขวา 60° ถ้ารถไหลเลยมุมที่ตั้ง ให้เพิ่ม `TURN_TOLERANCE_DEG` เพื่อเบรกเร็วขึ้น |
| ความไวในการรักษาแนวตรง | บรรทัด `amount =` และบรรทัด `trim +=` | 2 คือมุมเบนที่ยอมได้, 3 คือกำลังชดเชยต่อองศาที่เกิน, 80 คือเพดานส่วนต่างกำลัง ตัวเลข 16 ในบรรทัดถัด ๆ ไปจำกัดการเปลี่ยนต่อรอบ ลดขนาด 16 ทั้งสองฝั่งถ้าต้องการให้ค่อย ๆ ปรับขึ้นลง |
| ยก–ลดรางและหนีบ | `RACK_UP_COMMAND`, `RACK_UP_MS`, `RACK_DOWN_COMMAND`, `RACK_DOWN_MS`, `GRIP_RIGHT_CLOSED`, `GRIP_LEFT_CLOSED` | จูนทิศและเวลายก–ลด S1 แยกกัน แล้ววัดมุมหุบ S4 ขวาและ S5 ซ้ายกับกระป๋องจริง |
| หมุน S2 ที่จุดวางและหมุนคืนหลังปล่อย | `ROTATE_RIGHT_COMMAND`, `ROTATE_RIGHT_MS`, `ROTATE_RETURN_COMMAND`, `ROTATE_RETURN_MS` | ค่า 90 คือหยุด ค่าเริ่มต้นขากลับใช้คำสั่งตรงข้ามและเวลาเท่าขาไป ทำเครื่องหมายท่าเริ่มแล้วจูนเวลาคืนแยกตามโหลดจริง |
| ลำดับยก หนีบ หมุน หรือพฤติกรรมตอนค้นหา | `run_route` / `drive_to_station` | ฟังก์ชันแรกเรียงขั้นตอนแขน ฟังก์ชันที่สองตัดสินใจจาก NB142, HC-SR04 และเข็มทิศ |

### นำเข้าและลงบอร์ด

1. เปิด [MakeCode สำหรับ micro:bit](https://makecode.microbit.org/) แล้วเลือก **Import → Import URL**
2. วางลิงก์ `https://github.com/JT8966/can-gripper-robot` แล้วกดนำเข้า
3. เสียบสาย USB ที่ส่งข้อมูลได้จากคอมพิวเตอร์ **เข้าพอร์ต USB บนตัว micro:bit** แล้วกด **Download** ใน MakeCode
4. ถ้าเบราว์เซอร์บันทึกไฟล์ `.hex` ลงคอม ให้คัดลอกไฟล์นั้นไปที่ไดรฟ์ **MICROBIT** แล้วรอไฟด้านหลังบอร์ดหยุดกะพริบ ถ้าจับคู่บอร์ดผ่าน WebUSB แล้ว ปุ่ม Download จะส่งโปรแกรมลงบอร์ดโดยตรง [คู่มือโอนโปรแกรมของ MakeCode](https://makecode.microbit.org/device/usb)

## พอร์ตของหุ่น

| อุปกรณ์ | พอร์ต MOTION:BIT Pro |
|---|---|
| ล้อซ้าย 2 ตัว | ต่อทีละตัวที่คู่ M1A/M1B และคู่ M2A/M2B ทิศเดินหน้าคือ M1A และ M2A |
| ล้อขวา 2 ตัว | ต่อทีละตัวที่คู่ M3A/M3B และคู่ M4A/M4B ทิศเดินหน้าคือ M3A และ M4A |
| เซอร์โว 1 ยก–ลด rack | S1 |
| หมุนที่คีบขวา (360°) | S2 |
| ปากคีบขวาและซ้าย (180°) | S4 ขวา, S5 ซ้าย |
| HC-SR04 รุ่น 5V แบบ 4 ขา | VCC → ขา 5V, GND → GND, TRIG → P0, ECHO → P1 ผ่านตัวแบ่งแรงดัน |
| TCS3472 | I²C ใช้ SDA (P20), SCL (P19), GND และ 3V3 สำหรับโมดูลที่รองรับ |
| NB142 รุ่นเอาต์พุตดิจิทัล 5 ช่องที่รองรับ 3.3V | VCC → 3V3, GND → GND และเอาต์พุตซ้ายสุดถึงขวาสุด → P12, P13, P14, P15, P16 ที่ขา Signal ของ GPIO |

**ลดแรงดัน ECHO ก่อนต่อ P1** ต่อ ECHO → ตัวต้านทาน 10 kΩ → จุดร่วมที่ต่อเข้า P1 แล้วต่อจากจุดร่วมนั้นผ่านตัวต้านทาน 10 kΩ อีกตัวลง GND แรงดัน 5V จะลดเหลือประมาณ 2.5V [ผัง HC-SR04 สำหรับบอร์ด 3.3V](https://learn.adafruit.com/ultrasonic-sonar-distance-sensors/pinouts)

### ตั้งระยะและลำดับคีบ

คำสั่งเดินหน้าครั้งแรกส่งกำลัง 255/255 ไปยัง M1–M4 พร้อมกัน จากรอบถัดไปเข็มทิศจึงเริ่มชดเชยเมื่อรถเบน

- `PICKUP_DISTANCE_CM` คือค่า X วัดจากหน้าหัว HC-SR04 ตั้งไว้ **10 ซม. ชั่วคราว** วางกระป๋องที่ตำแหน่งหนีบจริงแล้วปรับค่านี้ หุ่นเบรกทันทีที่อ่านค่าใกล้ครั้งแรก และคีบเมื่อวัดซ้ำแล้วยังอยู่ในระยะ สัญญาณที่หมดเวลาจะไม่นับเป็นวัตถุ เซนเซอร์วัดได้ทั้งกระป๋องและวัตถุอื่นด้านหน้า
- ขณะเดินหน้า ล้อทั้งสี่หมุนไปข้างหน้า เมื่อทิศตรง รถใช้กำลัง 255/255 หากเบนเกิน 2° จะค่อย ๆ ผ่อนล้อด้านที่ต้องการเลี้ยวเข้าหา และคืนกำลังเมื่อกลับเข้าแนว กำลังสองฝั่งต่างกันได้สูงสุด 80 และปรับส่วนต่างครั้งละไม่เกิน 16 ตอนถอยล้อทั้งสี่ถอยพร้อมกัน ส่วนตอนหมุนขวา 90° ล้อซ้ายเดินหน้าและล้อขวาถอย
- `REVERSE_3CM_MS` คือเวลาถอย ตั้งต้น **50 มิลลิวินาที** ที่กำลังเต็ม ขีดจุดอ้างอิงแล้ววัดบนพื้นจริง เช่น ถ้าถอยได้ 2 ซม. ให้ลองปรับเป็น `50 × 3 / 2 = 75` มิลลิวินาที แล้ววัดซ้ำ
- เปิดเครื่องแล้วล้อหยุด S1 และ S2 รับค่าหยุด 90 จอแสดง ✓, S4 ขวาไป 10° และ S5 ซ้ายไป 20° จากนั้นรอ 1 วินาที จึงตรวจ TCS3472 หนึ่งครั้งและเตรียมเข็มทิศ ถ้าพบเซนเซอร์จะแสดง A ถ้าขึ้น I2C ให้ตรวจสายแล้วรีเซ็ต กด A เพื่อค้นหา เมื่อถึงระยะและยืนยันสี รถหยุด ลด S1 หนีบทั้งสองวง แล้วยก S1 ขึ้นเพื่อขน ปุ่ม B สั่งเบรกล้อ หยุด S1/S2 และค้างวงคีบทั้งสองตามมุมล่าสุด
- TCS3472 ต้องเห็นสีพื้นข้างกระป๋องขณะ HC-SR04 ยืนยันระยะสองครั้ง รถจำสีเหลือง แดง เขียว หรือน้ำเงิน และต้องเห็นพื้นอื่นที่มีแสงพออย่างน้อย 65 มิลลิวินาทีก่อนรับแถบสีเดิมเป็นปลายทาง เมื่อหยุดยืนยันสีตรงกันสองครั้ง รถลด S1 หมุน S2 เปิด S4 ขวา รอ 400 มิลลิวินาที เปิด S5 ซ้าย รออีก 400 มิลลิวินาที แล้วหมุน S2 คืนและยก S1 กลับ ถ้ากด B ขณะวิ่งขน กด A เพื่อขนต่อได้ หากหยุดระหว่างยกของหรือระหว่างวาง ให้ประคองกระป๋อง จัดรางและ S2 กลับท่าเริ่ม แล้วรีเซ็ตก่อนรอบใหม่
- วางแถบรับและแถบวางสีเดียวกันแยกจากกันบนแนวที่รถวิ่งผ่าน โดยมีพื้นสีกลางคั่น ให้ NB142 ยังติดครบเมื่อ TCS3472 อยู่เหนือแถบ จัดสนามไม่ให้รถย้อนเข้าแถบรับก่อนถึงจุดวาง เพราะใช้สีระบุตำแหน่ง ทดสอบเทปเหลือง แดง เขียว และน้ำเงินในแสงสนามจริงผ่าน Serial (`YELLOW`, `RED`, `GREEN`, `BLUE`) และปรับเกณฑ์ใน `floor_color()` หากสีถูกอ่านสลับกัน

### ทดลองกับหุ่นจริง

1. ปิดไฟก่อนย้ายสายเซอร์โวให้ตรงกับผัง S1/S2/S4/S5 ถ้าทุกตัวรองรับ 5V ให้ตั้ง VCC1 และ VCC2 ที่ 5V ตรวจพิกัดกระแสรวมของเซอร์โวขณะรับโหลด เพราะภาคจ่าย 5V ของบอร์ดรองรับสูงสุด 3A รวม [คู่มือ MOTION:BIT Pro](https://cdn.robotshop.com/media/C/Cyt/RB-Cyt-437/pdf/cytron-motionbit-pro-12v-robotics-expansion-board-for-microbit-datasheet.pdf)
2. ลองแขนโดยยังไม่ใส่กระป๋อง ดูว่าเวลา 500 ms พา S1 ถึงระดับคีบและพา S2 ถึงจุดปล่อยหรือไม่ หากถึงสุดรางก่อนเวลาที่ตั้งไว้ให้กด B แล้วลดเวลา ตรวจมุมอ้าและหุบของ S4/S5 กับกระป๋องทีละข้าง โดยเฉพาะ S5 ที่ยังใช้ 20° ทั้งสองท่า
3. ตั้ง NB142 ใต้หน้ารถ หันหัวอ่านลงพื้น ลองทีละช่องบนพื้นผิวที่ต้องการให้หุ่นเดินหน้า วัดขาสัญญาณเทียบ GND ถ้าได้ใกล้ 3.3V ตอนตรวจเจอ ใช้ `NB142_DETECTED_LEVEL = 1` ถ้าได้ใกล้ 0V ตอนตรวจเจอและใกล้ 3.3V ตอนพ้นพื้นผิวนั้น ให้ตั้งเป็น `0`
4. ปรับเทียบเข็มทิศตามคำแนะนำบนจอ ตรวจว่าการหมุนขวา 90° เพิ่มค่าทิศใกล้ 90° ในท่าติดตั้งจริง ลองขณะมอเตอร์ทำงานด้วย เมื่อไม่มีการแก้แนวแทรก หุ่นจะเบรกเมื่อวัดมุมหมุนได้อย่างน้อย 86° เพื่อเผื่อระยะไหลถึงเป้าหมาย 90° ปรับค่า TURN_TOLERANCE_DEG ตามมุมที่วัดได้บนพื้นจริง หากเข็มทิศอ่านไม่ได้ หรือหมุนไม่สำเร็จใน 5 วินาที รถจะหยุดและแสดง ✗ หากต้องการยกเลิกระหว่างรอบให้กด B [คู่มือเข็มทิศ MakeCode](https://makecode.microbit.org/reference/input/compass-heading)
